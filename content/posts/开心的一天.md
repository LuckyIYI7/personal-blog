## 前言

今天还是很开心的。。

从今年年初考完研之后就开始研究怎么学习魔法，因为隐约听说国外的 AI 工具非常好用，像 Gemini / ChatGPT / Claude Code。。不知不觉也从折腾电脑中获得了一点乐趣，今天算是初步把网络环境搭好了。

## 探索过程

### 第一站：geph（小厂 VPN）

一开始只是找了个免费的小厂 VPN 软件叫 geph，因为要求不高，只要能看看外面的世界就可以了。

后来在 YouTube 上看到有人科普，小厂 VPN 软件其实非常不安全——这种软件很不透明，安装之后它想监控数据、拿数据做坏事，用户是不知道的，而且它能看到我们发送的请求内容，还有 DNS 可能被劫持等问题。

吓得我赶紧研究别的办法。不过感觉运气还是很好的，我用的这个 geph 在 GitHub 上是有开源的。把源码 git clone 到本地后让 Codex 帮我分析了一下，结论是：geph 的架构是"本地 SOCKS5/HTTP/DNS/VPN 接管 + 远端出口节点 + 桥接/前置域名抗封锁"，有前置域名、硬编码公钥、默认本地监听、DNS 走隧道，比"裸代理 + 靠系统 DNS"的简单代理更稳妥，但仍然有一些潜在安全隐患。

另外在几个测试 IP 的网站测了一下 geph 的 IP，结果都是显而易见的机房 IP，10000+ 人在用，非常危险。。好在我还没充值任何海外服务，所以没有被封号。

### 第二站：Surfshark（大厂 VPN）

考虑到价格，尝试了传说中性价比很高的 Surfshark。还挺失望的，好像没那么好用（可能跟所在地区有关吧），只尝试了一个晚上就申请退款了，好在退款处理得很及时。

### 第三站：静态住宅 IP（目前方案）

多看了几个 YouTube 视频科普之后，发现对我来说很反直觉的一件事——我之前以为 VPN 是最常用的方法，结果看来 VPN 是最危险最不安全的方法。。此外还有像机场的动态节点（例如 Clash Verge）、买服务器自己搭建 VPS 节点、海外实名电话卡 + 数据漫游等各种办法。

一开始打算完全参考这个 YouTube 视频的方案（公共基础 + 静态 IP，PC 端用指纹浏览器，手机端用链式代理）：

> https://www.youtube.com/watch?v=yGgq0sB9HeA

后来没有完全参考，原因一是视频里用的静态住宅 IP 实在太贵了，我还只是个拿生活费的大学生，等开始赚钱再考虑吧；原因二是视频里的前置节点（公共机场）突然打不开了，而且我也不知道怎么自己再配另一个机场。

最后参考了这个视频，感觉更适合我，不用自己设置链式代理，价格也亲民很多：

> https://www.youtube.com/watch?v=kToFOqzVfh4

最终方案：在 **miya 平台**买了个美国住宅 IP，iOS 端用 **Shadowrocket**，PC 端用 **v2rayN** 和 **AdsPower**（目前还没想好分流的指纹浏览器效果更好，还是开启 TUN 模式的代理工具更好，索性两个都下了）。打算先用一段时间，稳定下来再考虑充值 AI 服务。。反正土区 Apple ID 还有很多余额 hh

## 各种魔法对比

| 方式 | 原理 | 优点 | 缺点 |
|---|---|---|---|
| VPN（如 geph、Surfshark） | 在本地和远端服务器之间建立加密隧道，流量经服务器出口访问目标网站 | 使用简单，一键连接 | 不透明，安全性差；IP 多为机房 IP，容易被检测；可能导致封号 |
| 机场动态节点（如 Clash Verge） | 通过第三方代理服务商提供的节点池，动态分配 IP 访问目标 | 节点多、速度快、价格适中 | 依赖服务商稳定性；配置相对复杂 |
| 自建 VPS 节点 | 租用海外服务器，自己搭建代理协议（如 V2Ray、Shadowsocks） | 完全自主可控，IP 质量好 | 需要一定技术能力；成本较高；服务器可能被封 IP |
| 静态住宅 IP（如 miya） | 使用真实家庭宽带 IP，通过代理工具（如 v2rayN、Shadowrocket）转发流量 | IP 纯净度高，不易被识别；适合注册海外服务 | 价格较贵；速度取决于住宅网络质量 |
| 海外实名电话卡 + 数据漫游 | 直接使用海外运营商 SIM 卡走海外网络 | 天然海外 IP，最接近真实用户 | 成本高；漫游费贵；不适合长期日常使用 |

## 总结

折腾了好几天，从 geph 到 Surfshark 再到静态住宅 IP，算是初步把网络环境搭起来了。最大的收获大概是：VPN 并不是最好的方案，IP 纯净度才是关键。先用这套方案稳定一段时间，后面赚钱了再考虑升级。。
